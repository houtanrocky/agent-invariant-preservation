# Reproducibility checklist

- [ ] Exact subject SHA, origin and license recorded; no floating baseline.
- [ ] OS, Python, Go, dependency locks, database image digest/isolation and UTC configuration captured.
- [ ] Baseline failures and healthy comparison environment independently reproduced.
- [ ] All accepted tasks have human reference/oracle/mutant evidence with hashes.
- [ ] Shared documentation and A/B prompts hashed; information parity reviewed.
- [ ] Agent versions, models, permissions, budgets, retries and session isolation verified.
- [ ] Randomized frozen schedule and database reset/schedule seeds recorded.
- [ ] Every attempt retained; raw records validated; exclusions reviewed with reasons.
- [ ] Analysis regenerates from observations only; missing measurements and denominators disclosed.
- [ ] Tables/figures trace to input checksums, code commit and command; paper compiles.
- [ ] Secrets redacted with preserved restricted originals; release permissions approved.
