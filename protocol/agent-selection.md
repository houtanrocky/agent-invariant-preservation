# Agent selection and verification

Select two accessible repository-editing agent systems after confirming permission, cost and repeatability.
No current agent CLI has been integrated or claimed to support undocumented flags. The example config
contains placeholders. Distinguish the effect of an agent scaffold from the underlying model: ideally
hold the model constant for scaffold comparisons, or explicitly treat system+model as the study unit.

Record executable version, model/provider/version, tools, documentation access, authentication method
(names only), context budget, wall time and price measurement method. Test a disposable repository
with no paid call where possible, then perform an explicitly authorized funded dry run.

Next: verify stdin/file prompt ingestion, noninteractive operation, exit semantics, budget enforcement,
session reset, output patch capture and token reporting. Complete docs/agent-execution.md's checklist.
