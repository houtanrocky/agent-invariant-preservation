# Research workflow

Read and log papers → inspect/pin baseline → define meaningful changes → build references and independent
oracles → reject deliberate defects → pilot → revise/freeze → execute independent sessions → review all
outcomes → analyze real records → trace claims into manuscript → audit and release with approved rights.

Each transition needs evidence, not a checked box alone. Use reading notes for interpretation, the decision
log for choices, daily logs for failed attempts, task reports for oracle validation and Git for source history.
Keep pilot/main phases separate; preserve protocol amendments and outcome visibility when decisions change.
