# Manuscript source and build

main.tex and sections/ are the primary manuscript sources. The text describes planned research;
results/discussion/conclusions remain structured placeholders. references.bib contains linked, checked
metadata; full-text synthesis is still pending. No empirical tables are auto-generated by compilation.

Install a conventional TeX Live or MiKTeX distribution with article, geometry, lmodern, hyperref,
booktabs and BibTeX. From the research root run `python scripts/build_paper.py`.
Equivalent commands inside paper/ (PowerShell and POSIX):

```text
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Missing executable means compilation did not occur. Install dependencies or run the manuscript CI job.
For undefined citations inspect key spelling, run BibTeX after the first TeX pass, then two more passes.
If package files are missing, install the named TeX package rather than removing needed citations.
Generated PDF/auxiliary files are ignored; keep all primary source and bibliography changes in Git.
