\section{Related Work}
SWE-bench and SWE-agent provide context for repository tasks and agent execution
\cite{swe-bench,swe-agent}. SWE-Bench+ raises questions about solution leakage and weak tests
\cite{swe-bench-plus}. These concerns motivate independent oracle validation and review of apparent
successes, rather than assuming that a passing score establishes semantic correctness.

QuickCheck presents randomized property checking \cite{quickcheck}. Property-Generated Solver
investigates property-based feedback for LLM code generation and refinement
\cite{property-generated-solver-v1,property-generated-solver-v2}; LISA studies LLM-based invariant
testing for functional bugs \cite{lisa}. A targeted full-text comparison now motivates positioning
this study as a bounded extension: fixed shared requirements and planning guidance during transactional
maintenance, evaluated using separate feature and persisted-state checks. No priority or superiority
claim follows. Version-specific notes and source sections are recorded in the literature directory.

The test-oracle, metamorphic-testing, mutation-testing and regression-testing literature provides
methodological context \cite{test-oracles,metamorphic-testing,mutation-testing,regression-testing}.
Isolation definitions, history-based anomaly detection and systematic concurrency testing motivate
careful state and interleaving checks \cite{sql-isolation,elle,chess}.
