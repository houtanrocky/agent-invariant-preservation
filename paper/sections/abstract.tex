\begin{abstract}
Coding agents can implement changes across software repositories, but requested-feature correctness
does not by itself establish preservation of transactional state requirements. This manuscript describes
a planned empirical study of coding agents modifying a Go marketplace backend. We propose a controlled
comparison of standard instructions and invariant-oriented guidance, holding the underlying available
requirements constant. Separate feature and invariant oracles will evaluate joint task success, with
task validation through human-reviewed references and deliberately defective implementations.
The study has not yet produced empirical observations. Results, effect estimates and conclusions
will be added only after protocol freeze, execution and evidence review.
\end{abstract}
