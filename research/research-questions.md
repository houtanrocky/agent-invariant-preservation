# Research questions

Core: How reliably can LLM coding agents implement modifications to stateful backend applications
while preserving existing transactional invariants?

| ID | Question | Planned evidence |
| --- | --- | --- |
| RQ1 | How often are both requested features and required invariants correct? | Joint and component success by task/system/condition |
| RQ2 | Does explicit invariant-oriented guidance improve correctness? | Within-task, within-system B−A success differences |
| RQ3 | Which invariant-violation categories occur most frequently? | Reviewed failed assertions and counterexample traces |
| RQ4 exploratory | How do time, tokens and tool interactions relate to correctness? | Missing-aware distributions and exploratory associations |

Operational definitions are in the protocol. No RQ currently has an empirical answer.
Next: review scope after the pilot and log any question change before observing main-study outcomes.
