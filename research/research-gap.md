# Research gap: evidence, interpretation and open claims

Established from checked sources (reading stages differ): SWE-bench evaluates repository issue resolution;
SWE-agent studies agent-computer interfaces; SWE-Bench+ reports leakage and weak-oracle concerns;
Property-Generated Solver uses property-oriented feedback; LISA investigates LLM-generated invariant
tests for functional bugs. See linked sources and reading status in the literature matrix.

Tentative interpretation: a focused controlled study of *maintenance changes* in a transactional backend,
using independent feature and state oracles, may provide useful evidence beyond issue-resolution scores.
Invariant guidance overlaps with property-based LLM refinement, and LISA is particularly close.
The [dated full-text comparison](../literature/pgs-lisa-comparison.md) narrows the proposed contribution
to a controlled extension in one transactional maintenance setting. It does not establish priority.

Unverified novelty claims: no assertion of priority, first study, unexplored field or universal agent weakness
is permitted. One repository and a small purposive task set support a bounded empirical contribution.

Next: continue backward/forward searching from the closest papers; compare unit of modification, guidance,
transactional setting, hidden oracles and outcome definitions. Record counterexamples that narrow the gap.
If overlap is strong, frame this as replication/extension with a new setting instead of a novelty claim.
